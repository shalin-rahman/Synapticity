# Playbook: Zero-Defect Code Quality (Principal Engineer Grade)

This playbook defines the mandatory quality standards for all code generated by the Synaptic Framework. Follow these rules to ensure production-grade stability and pass all automated linters (Pylint, Flake8, MyPy).

## 1. Zero-Trust Linting
- **PEP8 Compliance**: All Python code must strictly follow PEP8. This includes:
    - Exactly 4 spaces for indentation.
    - Max line length of 88 characters (Black style).
    - Clear separation of imports (Standard Lib, Third-Party, Local).
- **No Unused Variables**: Never declare a variable or import that isn't used.
- **Explicit Returns**: Every function must have an explicit return path, including `None` if applicable.

## 2. Robust Type Safety
- **Type Hinting**: All function signatures MUST include type hints for every argument and the return value.
- **Pydantic v2**: If handling data models, use Pydantic v2 `BaseModel` for validation.
- **Checkable Code**: Ensure code passes `mypy --strict` whenever possible.

## 3. Defensive Programming
- **Error Handling**: Encapsulate external I/O or network calls in specific `try...except` blocks with precise exception types. Never use a bare `except:`.
- **Validation**: Validate all inputs at the entry point of a function.
- **Graceful Failure**: Always provide a fallback or sensible error message if a core component fails.

## 4. Documentation & Docstrings
- **Google Style**: Use the Google Python Style Guide for all docstrings.
- **The "Why", not the "What"**: Comments should explain the rationale behind non-obvious logic, not just restate the code.

## 5. Architectural Idioms
- **SOLID Principles**: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion.
- **Factory Patterns**: Use factories or adapters when dealing with multiple providers.
- **Async Efficiency**: Use `asyncio` for I/O bound operations to maximize throughput.

Applying this skill ensures that every line of code produced is ready for an enterprise-grade CI/CD pipeline.
