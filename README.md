# The State of Intelligent Connection (v2.0)

> A Staff-Engineer level autonomous SDLC system designed for zero-cost, high-IQ software production using a hybrid Cloud (Gemini) and Local (Ollama) intelligence model.

---

## Overview

synaptic is a professional-grade multi-agent framework that automates the entire software development lifecycle—from objective mapping to technical hand-off. It features self-healing code loops, hardened runtime verification, and human-in-the-loop gating for absolute operational reliability.

## Core Features

- **Staff-Tier Intelligence**: Personas architected for high-stakes decision making.
- **Multi-Account Key Pool**: Automatic key rotation for Gemini to bypass rate limits (Zero Cost).
- **Secure Verify-Loop**: Real-time code execution in sandboxes with `Bandit` security scanning.
- **synaptic Doctor**: Instant diagnostic suite for environment health.
- **Skill Injection**: Industrial-grade technical playbooks (Next.js, FastAPI, TypeScript) injected dynamically into agent context.
- **Automated Hand-off**: High-quality `TECHNICAL_DOCS.md` generated for every mission.

## Quick Start

### 1. Installation

Install the professional dependency stack:

```bash
pip install google-genai requests python-dotenv rich pydantic-settings cryptography bandit pytest
```

### 2. Configuration

Copy `.env.example` to `.env` and add your Gemini API keys from [AI Studio](https://aistudio.google.com/app/apikey).

### 3. Verification

Check if your local AI environment is healthy:

```bash
./sync doctor
```

### 4. Launch a Mission

Start your first autonomous software build:

```bash
./sync launch "my-project" "A high-performance FastAPI microservice for user auth."
```
